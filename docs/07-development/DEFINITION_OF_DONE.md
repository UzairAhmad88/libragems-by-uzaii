# Definition of Done

A feature is done only when:
- Requirements and acceptance criteria are met.
- UI works at mobile, tablet and desktop breakpoints.
- Loading, empty, success and error states are handled.
- Accessibility basics are checked.
- Server-side validation and authorization are in place where needed.
- No secrets or sensitive customer data are exposed.
- Tests, lint and TypeScript checks pass.
- SEO behavior is correct for public pages.
- Documentation is updated.
- The feature is reviewed against the approved design.
