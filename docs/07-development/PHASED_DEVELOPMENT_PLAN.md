# Phased Development Plan

## Phase 0 – Discovery and approvals
Deliverables: client checklist complete, verified contacts, approved product facts, assets inventory, final scope.

Exit gate: client approves business facts and scope.

## Phase 1 – Brand and UX
Deliverables: design tokens, sitemap, wireframes, responsive page designs, component inventory.

Exit gate: desktop and mobile designs approved.

## Phase 2 – Project foundation
Deliverables: Next.js setup, TypeScript, linting, formatting, environment validation, base layout, design tokens.

Exit gate: app runs locally and CI checks pass.

## Phase 3 – Public website
Deliverables: home, about, catalogue, three product pages, quality/sourcing, contact, legal pages, blog templates.

Exit gate: responsive public pages with approved content.

## Phase 4 – Data and admin
Deliverables: Supabase schema, RLS, admin auth, product CRUD, image management, enquiry dashboard.

Exit gate: authorization tests pass; no public access to private enquiries.

## Phase 5 – Enquiry integrations
Deliverables: validated form, spam protection, database persistence, email notification, WhatsApp links.

Exit gate: end-to-end tests pass with test inbox and confirmed WhatsApp number.

## Phase 6 – SEO and analytics
Deliverables: metadata, canonical URLs, sitemap, robots, schema, Search Console and analytics setup.

Exit gate: production crawl and SEO audit show no critical issues.

## Phase 7 – QA and hardening
Deliverables: functional, accessibility, security, performance, responsive and browser testing.

Exit gate: all P0 defects resolved.

## Phase 8 – Deployment and handover
Deliverables: production deployment, domain/HTTPS, backups, admin handover, documentation.

Exit gate: client signs off launch checklist.

## Phase 9 – Ongoing improvement
Deliverables: monthly search review, new educational content, product updates and maintenance.
