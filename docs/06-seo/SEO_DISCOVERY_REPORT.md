## 1. Executive Summary & SEO Governance

The objective of the LibraGems search strategy is to establish **durable, organic search visibility for high-intent B2B gemstone buyers**, positioning Libra Gems & Trading Co., Ltd. as an authoritative Bangkok supplier of rough gemstones, minerals, beads, and cut colored stones.

### Ethical SEO Principles:
1. **Zero Artificial Manipulation:** No keyword stuffing, hidden text, automated doorway pages, fake reviews, or private blog networks (PBNs).
2. **No Fabricated Search Metrics:** Search volume and keyword difficulty metrics are **not fabricated**. Preliminary keyword clusters represent structural search themes derived from real-world trade vocabulary. Formal quantitative volume data will be captured via Google Keyword Planner, Ahrefs, or Semrush in Phase 06.
3. **Accuracy in Claims:** Never optimize for terms the business cannot substantiate (e.g., claiming "mine-direct" or "untreated" if unverified).
4. **B2B Search Intent Alignment:** Optimize for commercial research and supplier acquisition queries, not mass-market retail consumer jewellery searches.

## 2. Search Intent Analysis: B2B Wholesale vs. B2C Retail

Understanding search intent is essential to prevent attracting low-intent consumer traffic that inflates bounce rates without generating enquiries:

```

│                       SEARCH INTENT DIFFERENTIATION                         │
├──────────────────────────────────────┬──────────────────────────────────────┤

│ • "rubellite necklace price"         │ • "afghanistan cut rubellite stone"  │
```

- *"What is the parcel weight and sizing distribution?"*
- *"Is the material stabilized or natural?"*
- *"Can this company provide legitimate export documentation from Bangkok?"*
- *"Can I inspect the stones in person or request video footage?"*

## 4. Information Architecture & Hub-and-Spoke Internal Linking

To maximize search engine crawl efficiency and build topical authority, the site architecture follows a **Hub-and-Spoke content hierarchy**:

```
                                  HOMEPAGE
                           (Broad Trading Entity)
                                     │
           ┌─────────────────────────┼─────────────────────────┐
           ▼                         ▼                         ▼
      ABOUT PAGE             GEMSTONE CATALOGUE       QUALITY & SOURCING
  (Corporate Entity)          (Main Topic Hub)        (Trust & Disclosure)
                                     │
         ┌───────────────────────────┼───────────────────────────┐
         ▼                           ▼                           ▼
  HESSONITE GARNET               TURQUOISE              AFGHAN RUBELLITE
 (Spoke 1: Rough Garnet)   (Spoke 2: Mineral Rough)  (Spoke 3: Cut Gemstone)
         │                           │                           │
         └───────────────────────────┼───────────────────────────┘
                                     │
                                     ▼
                              INSIGHTS & GUIDES
                 (Educational Support Articles & Gem Knowledge)
```

### Internal Linking Rules:
1. Every gemstone landing page links to:
   - Primary Catalogue Hub (`/gemstones`) via BreadcrumbList.
   - Sourcing and Quality page (`/quality-sourcing`) to reinforce grading transparency.
   - Dedicated Contact & WhatsApp enquiry CTA.
2. The Insights/Blog articles link contextually to the relevant gemstone landing page using descriptive anchor text (e.g., *"inspect our available rough hessonite garnet lots"*).

## 5. Structured Data (Schema.org) Strategy for B2B Non-Transactional Sites

A common pitfall on B2B catalogue websites is improperly implementing Google Schema `Product` markup with missing or invalid `Offer` / `price` properties, triggering Google Search Console rich-result errors.

### Schema Architecture for LibraGems:

```
  ┌───────────────────────────────────────────────────────────────────────────┐
  │                           SCHEMA.ORG BLUEPRINT                            │
  ├───────────────────────┬───────────────────────────────────────────────────┤
  │ Page Type             │ Target Schema Types                               │
  ├───────────────────────┼───────────────────────────────────────────────────┤
  │ Global / Root         │ • Organization (Legal name, address, contact)     │
  │                       │ • WebSite (Site name, URL, search target)         │
  ├───────────────────────┼───────────────────────────────────────────────────┤
  │ Contact & About       │ • LocalBusiness / Store (Bang Rak geocoordinates) │
  ├───────────────────────┼───────────────────────────────────────────────────┤
  │ Gemstone Landers      │ • BreadcrumbList (Hierarchical navigation)        │
  │                       │ • Product (B2B Price-on-Application specification)│
  ├───────────────────────┼───────────────────────────────────────────────────┤
  │ Insights / Knowledge  │ • Article (Author, publisher, datePublished)      │
  └───────────────────────┴───────────────────────────────────────────────────┘
```

### Non-Transactional Product Schema Configuration:
To comply with Google Search Central guidelines while reflecting wholesale trading reality:
```json
{
  "@context": "https://schema.org/",
  "@type": "Product",
  "name": "Commercial-Quality Rough Hessonite Garnet",
  "description": "Commercial-grade rough Hessonite Garnet parcels for lapidary cutting and bead processing, supplied by Libra Gems & Trading Co., Ltd. Bangkok.",
  "image": "https://libragems.net/images/products/hessonite-garnet/lot-main.jpg",
  "category": "Rough Gemstones",
  "brand": {
    "@type": "Brand",
    "name": "LibraGems"
  },
  "offers": {
    "@type": "AggregateOffer",
    "priceCurrency": "USD",
    "price": "0",
    "priceSpecification": {
      "@type": "UnitPriceSpecification",
      "priceType": "https://schema.org/PriceOnApplication"
    },
    "availability": "https://schema.org/InStock",
    "url": "https://libragems.net/gemstones/hessonite-garnet"
  }
}
```
