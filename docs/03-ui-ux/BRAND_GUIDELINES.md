# Brand Guidelines

## Brand personality
Premium, natural, knowledgeable, dependable, understated and international.

## Colour system
| Role | Colour | Hex |
|---|---|---|
| Primary forest green | Deep forest | `#174C38` |
| Dark green | Deep shade | `#103729` |
| Warm background | Off-white beige | `#F3EFE5` |
| Surface | Soft ivory | `#FAF8F2` |
| Accent | Muted champagne | `#B99B68` |
| Body text | Charcoal | `#242A26` |
| Muted text | Stone grey | `#6E756F` |
| Borders | Warm grey | `#DDD8CC` |

The 60/30/10 ratio is a visual guideline, not a requirement that every screen contain exact measured percentages. Forest green should anchor the identity, warm beige should provide the main canvas, and champagne should be used sparingly.

## Typography
- Display/headings: refined serif family (for example, Cormorant Garamond or an equivalent licensed/available font).
- Body/UI: readable sans-serif (for example, Inter or equivalent).
- Avoid tiny text and overly decorative body fonts.

## Layout
- Generous whitespace.
- Strong grid and alignment.
- Restrained borders and shadows.
- Large authentic gemstone photography.
- Consistent spacing and content width.
- Calm transitions; avoid excessive animation.

## Imagery
- Use actual company product images for product listings.
- Keep lighting and backgrounds consistent where possible.
- Do not imply stock photography is company inventory.
- Alt text should describe what is genuinely visible, not add unsupported sales claims.
