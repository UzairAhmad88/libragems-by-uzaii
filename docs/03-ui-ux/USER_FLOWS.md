# User Flows

## Product enquiry through WhatsApp
Search engine / referral → product landing page → review images and facts → click product-specific WhatsApp CTA → prefilled message opens → visitor sends message → business responds.

## Product enquiry through website form
Visitor → contact/product page → complete validated form → server validates and rate-limits → enquiry saved → notification email sent → confirmation displayed → administrator reviews enquiry.

## Product administration
Admin → sign in → server verifies session and role → manage products/images → publish changes → public product pages revalidate and display approved content.

## UX requirements
- Always make the next action obvious.
- Use clear labels and concise copy.
- Keep forms short.
- Preserve form values after recoverable errors.
- Show accessible loading, success and error states.
- Do not use deceptive urgency or fabricated availability.
