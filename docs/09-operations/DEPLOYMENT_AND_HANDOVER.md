# Deployment and Handover

## Before deployment
- Confirm production domain and DNS access.
- Create production Supabase project.
- Configure production environment variables.
- Configure transactional email sender and verify domain.
- Create initial admin account securely.
- Apply database migrations and RLS policies.
- Upload approved product photographs.
- Verify contact and WhatsApp details.
- Review privacy and legal pages.

## Deployment
- Deploy through the approved Vercel project.
- Configure production environment variables.
- Configure domain and HTTPS.
- Test redirects and canonical host.
- Keep preview/staging deployments out of search indexing.
- Run production smoke tests.

## After deployment
- Submit sitemap in Google Search Console.
- Verify GA4 events and enquiry conversion tracking.
- Test email delivery.
- Test WhatsApp on mobile and desktop.
- Confirm backup and recovery process.
- Provide admin training and access handover.

## Handover items
- Source repository access
- Hosting account ownership
- Domain/DNS ownership
- Database project ownership
- Admin account instructions
- Environment variable inventory (not secret values)
- Backup/restore instructions
- Content update instructions
- Known limitations and future enhancements
