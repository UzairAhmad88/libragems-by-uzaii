# User Roles

## Public visitor
- Browse company information and gemstones.
- Read educational articles.
- Contact the business through WhatsApp, email or enquiry form.

## Content administrator
- Sign in securely.
- Create and edit product records.
- Upload and manage product images.
- Publish, unpublish or archive products.
- View enquiries and update their status.
- Edit SEO title and description fields.

## Technical administrator
- Manage deployment, database, authentication, environment secrets and backups.
- Assign content administrator access.
- Review security and operational logs.

Use least-privilege access. Public users must never be able to read private enquiries or modify catalogue records.
